# nba-2026-prediction
Using computer vision and data analysis for forecasting the results of NBA 2026-2027 season.

The goals/tasks of this project are:
1. Collect matches using web scraping.
2. Track players, ball, baskets and field and map the positions of them into a 2D figure using convolutional neural networks.
3. Track and map the positions into 3D figures (players with joints, ball bouncing up and down, etc.).
4. Extract basic data from the matches: points, assists, rebounds (box score numbers).
5. Extract (more advanced) data for players' impacts and tactics analysis (e.g. offensive runs, defensive shapes, gravity(Curry), anti-gravity(Wembanyama), etc.).
6. Predict results before matches.
7. Predict results online.
8. Create a (2D) live analysis website.
9. Optional: Develop a new game score system
